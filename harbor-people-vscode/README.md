# Harbor People Website — VS Code Export

## Requirements

- Node.js 20.19+ (Node 22 or 24 recommended)
- npm 10+ or pnpm 9+

## Run in VS Code

1. Extract this folder.
2. Open the extracted `harbor-people-vscode` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Install dependencies:

```bash
npm install
```

5. Start the website:

```bash
npm run dev
```

6. Open the local URL shown in the terminal, usually `http://localhost:5173`.

The standalone export uses port 5173 and `/` automatically, so no environment variables are required.

## Useful commands

```bash
npm run typecheck
npm run build
npm run serve
```
